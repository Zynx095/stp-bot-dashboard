# STP Cleaning Robot Dashboard

An automated Sewage Treatment Plant (STP) cleaning system designed to reduce hazardous human involvement in toxic environments through robotics, computer vision, and remote monitoring.

This project combines embedded systems, object detection, and a browser-based control dashboard to create a low-cost intelligent cleaning solution.

---

## Features

- Remote robot control dashboard
- Arduino-powered movement system
- YOLO-based object detection integration
- Real-time monitoring interface
- Autonomous obstacle awareness
- Low-budget robotics implementation

---

## Tech Stack

- Arduino Mega
- HTML/CSS/JavaScript
- YOLO Object Detection
- Embedded C++
- Sensor Integration

---

## Project Goal

To create a practical and affordable robotic system capable of assisting in hazardous sewage treatment cleaning operations while minimizing direct human exposure.
